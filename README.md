# Python-Full-Stack-Web-Development
# User Management System

## Project Overview

The User Management System is a simple Python Full Stack Web Application developed using Flask, HTML, CSS, and SQLite. This project allows users to add and manage user details such as name and email through a web interface.

The application demonstrates the integration of frontend, backend, and database technologies in a single web application.

---

# Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite Database

---

# Features

- Add new users
- Store user information in database
- Display registered users in a table
- Responsive and clean user interface
- Simple full stack implementation

# Installation

## Step 1: Install Python

Make sure Python 3.10 or higher is installed.

---

## Step 2: Install Flask

Open terminal and run:

pip install flask

---

# Run the Project

Open terminal inside the project folder and run:

python app.py

---

# Open in Browser

http://127.0.0.1:5000/

---

# Output

The application will display:

- User input form
- Registered users table
- Stored user records from SQLite database
